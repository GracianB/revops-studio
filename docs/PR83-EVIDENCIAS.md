# PR83 · Registro de requisitos de evidencia

**No publicado.** Rama de borrador apilada sobre PR82.

Cada tarea PR81 exige un criterio verificable, una función responsable, una categoría y los riesgos PR82 relacionados. Se genera un libro de requisitos, **no** un registro de firmas ni de evidencias recibidas.

La simulación permite marcar requisitos como ensayados durante la demo; impide marcar la autorización externa y nunca eleva el contador de pruebas empresariales, ejecuciones o aprobaciones reales. No se guardan nombres, documentos, comentarios, archivos ni datos personales.

La exportación JSON usa propiedades seleccionadas expresamente y distingue requisitos ensayados de evidencias verificadas. Hay pruebas para las 18 recetas de los tres escenarios, protección de datos, duplicados, mezcla de escenarios y falsificación de aprobación.

Este módulo se integrará visualmente en el centro de control PR85. El uso real requiere repositorio autorizado de pruebas, responsables identificados y validación humana fuera de la demo.
