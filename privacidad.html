RevOps Studio / Información de contacto

Privacidad sin sorpresas.

Esta página describe qué sucede cuando envías una consulta a RevOps Studio. No introduzcas contraseñas, documentos privados ni información sensible de terceros.

Quién responde a las consultas

Gracián Baena González, Murcia (España). Contacto: gracianbaenagonzalez@gmail.com.

Qué datos se solicitan y para qué

Nombre, dirección de correo, tipo de servicio y descripción del problema. Las herramientas actuales y horas semanales son opcionales. El objetivo exclusivo del formulario es estudiar tu solicitud y responder sobre una posible colaboración.

Cómo se realiza el envío

El formulario utiliza FormSubmit, un proveedor externo de recepción y reenvío de mensajes. Si pulsas «Enviar solicitud» y autorizas el tratamiento, los datos se transmiten desde tu navegador a FormSubmit para hacerlos llegar al correo indicado. También puedes escribir directamente mediante tu propia aplicación de email, sin utilizar este formulario.

Base y tiempo de conservación

La base para enviar y responder la consulta es tu consentimiento al solicitar contacto. Los mensajes se conservarán durante el tiempo necesario para atender la conversación y, si se concreta un servicio, durante los periodos que exija la normativa aplicable. FormSubmit puede aplicar sus propias condiciones y periodos; no afirmamos que el proveedor almacene los datos únicamente en la UE.

Tus derechos

Puedes solicitar acceso, rectificación, supresión, limitación u oposición y, cuando corresponda, portabilidad, así como retirar tu consentimiento, escribiendo al correo anterior. También puedes acudir a la Agencia Española de Protección de Datos (AEPD) si consideras que tus derechos no han sido atendidos.

Otros aspectos técnicos

La web se sirve desde GitHub Pages. El tema visual puede guardarse en el almacenamiento local del navegador. Para revisar el formulario completado antes o después del envío se utiliza el almacenamiento de sesión, si está permitido. No utilizamos ese almacenamiento como base de datos remota de contactos.
